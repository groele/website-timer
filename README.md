## 安装步骤

### 1. 准备图标文件（可选）
按照 `icons/README.md` 的说明准备PNG图标文件，或暂时跳过此步骤。

### 2. 在Chrome中加载扩展
1. 打开Chrome浏览器
2. 地址栏输入：`chrome://extensions/`
3. 开启右上角的"开发者模式"
4. 点击"加载已解压的扩展程序"
5. 选择 `website-timer-extension` 文件夹

### 3. 验证安装
- 扩展图标应出现在浏览器工具栏
- 点击图标应弹出统计界面
- 开发者工具控制台无错误信息

## 测试功能

### 基础功能测试
1. **时间统计测试**
   - 访问几个不同的网站（如baidu.com, zhihu.com）
   - 在每个网站停留1-2分钟
   - 点击扩展图标查看统计数据

2. **标签页切换测试**
   - 开多个标签页
   - 来回切换标签页
   - 验证时间统计的准确性

3. **窗口焦点测试**
   - 切换到其他应用程序
   - 返回Chrome
   - 验证失去焦点时停止计时

4. **数据持久化测试**
   - 关闭并重新打开浏览器
   - 检查统计数据是否保留

### 界面功能测试
1. **刷新功能**：点击"刷新"按钮更新数据
2. **重置功能**：点击"重置今日数据"清空统计
3. **确认对话框**：验证重置确认机制

## 调试工具

### 1. 查看后台脚本日志
- 访问：`chrome://extensions/`
- 找到扩展，点击"检查视图 service worker"

### 2. 查看存储数据
- 打开开发者工具
- 进入Application > Storage > Extension storage
- 查看存储的统计数据

### 3. 常见问题排查

**问题：扩展图标不显示**
- 检查manifest.json语法是否正确
- 确认图标文件路径是否存在

**问题：时间统计不准确**
- 检查浏览器控制台错误
- 验证权限是否正确授予

**问题：界面显示异常**
- 检查popup文件是否完整
- 验证CSS文件加载是否正常

## 扩展功能详解

### 核心特性
- **实时监控**：自动跟踪活跃标签页时间
- **智能暂停**：窗口失焦或用户空闲时暂停计时
- **数据存储**：本地存储，支持7天历史记录
- **用户友好**：直观的统计界面和操作

### 技术特点
- **Manifest V3**：使用最新的扩展标准
- **Service Worker**：高效的后台处理
- **内容脚本**：页面活动状态检测
- **响应式设计**：适配不同屏幕尺寸
